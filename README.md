🇺🇸 EN/US

Email Sender is a Python tool designed to automate personalized HTML email delivery through an SMTP server.

It uses CSV files to organize recipients, subjects, and links, along with an HTML template to customize messages. It also records execution results in a log file, making it easier to monitor email-sending operations and identify potential errors.

-----

🇧🇷 PT/BR

O Email Sender é uma ferramenta desenvolvida em Python para automatizar o envio de e-mails personalizados em HTML por meio de um servidor SMTP.

O sistema utiliza arquivos CSV para organizar os destinatários, assuntos e links, além de um template HTML para personalizar as mensagens. Também registra os resultados em um arquivo de log, facilitando o acompanhamento dos envios e a identificação de possíveis erros.
